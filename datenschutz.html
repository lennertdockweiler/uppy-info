Datenschutzerklärung für Uppy

Stand: 27. November 2026

Was Uppy ist

Uppy ist ein privates Werkzeug, das nur von seinem Betreiber genutzt wird. Es lädt selbst produzierte Videos auf den eigenen YouTube-Kanal und das eigene TikTok-Konto des Betreibers hoch.

Welche Daten verarbeitet werden

  • Uppy nutzt die YouTube Data API ausschließlich mit der Berechtigung youtube.upload, um Videos hochzuladen.
  • Die Anmeldedaten (OAuth-Token) werden nur lokal auf dem Gerät des Betreibers gespeichert und nicht an Dritte weitergegeben.
  • Uppy liest, speichert oder teilt keine Daten anderer Nutzerinnen und Nutzer und ruft keine YouTube-Inhalte ab.
  • Es gibt keine Werbung, kein Tracking und keine Analyse-Dienste.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Uppy nutzt Daten aus Google-APIs gemäß der Google API Services User Data Policy.

Siehe auch die Datenschutzerklärung von Google und die Nutzungsbedingungen von YouTube.
